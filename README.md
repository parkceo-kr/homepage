# 박승애 (Seungae Park) 개인 홈페이지

지란지교소프트 대표이사 박승애의 개인 홈페이지입니다.
공개된 기사, 인터뷰, 칼럼 등 인터넷에 공개된 정보를 바탕으로 제작했습니다.

## 구성

- **소개** — 대표이사 약력과 지란지교소프트 소개
- **걸어온 길** — 2012년 입사부터 대표이사까지의 경력 연표
- **수상** — 과기정통부 장관 표창 등 주요 수상 내역
- **인터뷰** — 매경 LUXMEN, 뉴시스, 데일리시큐, IT조선 등 언론 인터뷰 모음
- **칼럼** — 이투데이 시론 등 기고글 모음
- **연결** — LinkedIn, 브런치, 회사 홈페이지 링크

## 기술 스택

- 단일 정적 페이지 (`index.html`), 별도 빌드 과정 없음
- [Vercel](https://vercel.com)에 배포

## 배포

이 저장소는 Vercel과 연동되어 있어 `main` 브랜치에 푸시하면 자동으로 배포됩니다.
